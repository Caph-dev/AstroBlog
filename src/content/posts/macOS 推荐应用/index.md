## 效率工具

- Deck：最好用的剪贴板 https://deckclip.app/ 

- Alfred 5 多功能启动器

  推荐的 Workflows：

  - Alfred Gallery
  - Edit Clipboard
  - GitFred
  - New File
  - PathFind
  - Recent Files
  - Window Switcher

- BetterAndBetter：https://www.better365.cn/bab2.html **全局手势**

- Hammerspoon：配合 [[微信输入法]] [[豆包输入法]] 使用 https://github.com/Paxxs/Doubao-ime-hammerspoon

- iGet：文本划选增强 https://www.better365.cn/h-col-197.html

- Dropover：文件暂存架 https://dropoverapp.com/

- Orbit：手势为主的径向应用切换器 https://github.com/yuzeguitarist/Orbit

- Ghostty：美观的终端模拟器，配合 https://github.com/lewislulu/terminal-setup 一键配置

- Zap：完全开放的 Agentic 终端 https://github.com/zerx-lab/zap
